# پوسته اپ موبایل ووکامرس

افزونه تبدیل ظاهر موبایل فروشگاه ووکامرس به تجربه‌ای شبیه اپلیکیشن.

## ویژگی‌ها
- رابط موبایلی اختصاصی
- Bottom Navigation
- Splash Screen
- PWA foundation
- تم‌های مختلف
- صفحه خانه موبایلی
- کارت محصول مینیمال
- ساختار مناسب Home Builder
- آماده توسعه جستجوی Ajax، فیلتر Bottom Sheet، OTP و Push Notification
