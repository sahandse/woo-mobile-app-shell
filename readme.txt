== Description ==
Woo Mobile App Shell provides a mobile-first WooCommerce presentation layer with bottom navigation, app-like styling and PWA-ready foundations.

== Installation ==
1. Upload the woo-mobile-app-shell folder to /wp-content/plugins/
2. Activate the plugin.
3. Open WooCommerce > اپ موبایل.
